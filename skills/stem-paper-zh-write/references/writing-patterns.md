# 理工中文 — 推荐写法（替代套话）

## 绪论 / 背景

- 用 **具体场景或约束** 开头：数据规模、时延上限、能耗预算、标准条款号
- 点明 **已有方案的一条具体不足**（引用文献 + 现象），再写本文做法
- 「意义」写成 **可验证命题**：「若 X 成立，则可在 Y 条件下将 Z 降到 …」

## 相关工作

- 按 **问题线索** 组织，不按「国内 / 国外」空分
- 每条：工作做了什么 → 假设是什么 → 与本文设定差在哪（一句话）

## 方法

- 先 **问题形式化**（符号与输入输出），再算法步骤
- 步骤用动词开头：「计算」「更新」「判定」，少用「进行……的处理」
- 复杂度、假设、失败模式各用短段说清楚

## 实验

- 先 **基线与公平性**（同数据、同预算），再报指标
- 数字带单位；对比写清 **涨跌幅** 或 **绝对差**
- 异常结果一句话解释（配置、随机种子、样本过滤），不甩锅「有待进一步研究」

## 结论

- 三条以内：**做了什么 → 主要结果（数字）→ 局限（具体）**
- 展望写 **可做的下一个实验**，不写「未来研究将重点关注」

## 句长与节奏

- 交替短句与中句；避免连续三个以上 40 字以上的长句
- 一段一个中心论点；段首第一句说清本段要证什么
