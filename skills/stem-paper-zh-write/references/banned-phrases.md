# 理工中文论文 — 禁用套话与 AI 腔（写作 + 润色共用）

出现下列写法时：**删除、改写为具体事实或具体缺口**，不得换同义套话糊弄。

## 开场与背景

- 在当今社会 / 随着……的快速发展 / 近年来 / 在……背景下
- 众所周知 / 不言而喻 / 毋庸置疑
- 进入新时代 / 纵深推进 / 赋能 / 助力 / 抓手 / 闭环 / 落地

## 意义与拔高（无证据时禁止）

- 具有重要意义 / 深远意义 / 重大价值
- 提供了新的思路 / 新视角 / 新范式（除非明确对比前人并点名差异）
- 广阔的应用前景 / 巨大的潜力 / 广阔的发展空间
- 推动……发展 / 促进……升级（空泛、无对象无机制）

## 机械结构与衔接

- 首先……其次……再次……最后……（连续排比列举正文论点）
- 一方面……另一方面……（无实质对立或权衡时）
- 综上所述 / 总而言之 / 总之（段段收尾；**结论节最后一段**可用一次简短收束，禁止套话堆叠）
- 基于上述分析 / 基于以上讨论 / 由此可见（后面没有具体指代时）

## 伪深刻与英文直译腔

- 值得注意的是 / 需要指出的是 / 不难发现
- 从……角度来看 / 从某种意义上说 / 在一定程度上
- 不仅……而且……（连续多句）
- 旨在 / 致力于（可改为「本文做/用/实现」等具体动词）

## 空泛修饰（无数据、无对照实验时禁止）

- 显著 / 有效 / 充分 / 全面 / 深入 / 较好 / 良好 / 合理 / 科学
- 大幅提升 / 明显改善 / 极大提高（改：给出数值、基线、统计检验）

## 模板化段落节奏（禁止每段同一骨架）

背景 → 问题 → 意义 → 方法 → 意义（循环）

改为真人常见推进：**谁做了什么 → 差在哪 → 本文具体怎么做 → 验证方式**。

## 允许保留

- 学校/模板要求的 **章节标题与小节标题**（如「研究背景与意义」）
- 国标/领域 **规范术语**（首次可「中文全称（英文缩写）」）
- 有数据支撑的「显著」（须同句或邻句有 **p 值 / 置信区间 / 效应量 / 对照**）
